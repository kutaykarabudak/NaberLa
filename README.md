# NaberLa 🎶📷

Welcome to the **NaberLa** project, a web experience inspired by the original naberla.com! 

## Concept
NaberLa provides a unique, endless-scrolling feed of model Instagram posts. While you explore the visual content, a curated selection of house and trip music sets the mood in the background.

## Features
- **Endless Scrolling**: A continuous feed of curated posts.
- **Interactive UI**: Hover over any post to see exactly who the post belongs to (glassmorphism effect).
- **Direct Integration**: Click on any post to instantly view the original content on Instagram.
- **Vibe Setup**: Background music plays seamlessly to enhance your scrolling experience.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone <repo-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd NaberLa
   ```
3. Open `index.html` in your web browser (or use an extension like Live Server in VSCode).

## Technologies Used
- HTML5
- CSS3 (Custom Properties, Glassmorphism, Animations)
- Vanilla JavaScript
